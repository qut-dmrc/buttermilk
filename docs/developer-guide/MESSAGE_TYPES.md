# Buttermilk Group Chat Message Types

- **AgentOutput**: Used for standard responses from agent execution, including processed results, structured data, analysis, or completed tasks.

- **ErrorEvent**: Used for broadcasting error information, such as system errors, processing failures, or any other error condition that needs to be communicated.

- **UIMessage**: Used for messages sent to the manager (user/UI) when input or feedback is required, like requesting user confirmation, asking for choices, or seeking clarification.

- **ManagerMessage**: Used for responses from the manager (user/UI) back to the system, providing feedback, decisions, or responding to UIMessage prompts.
