# Buttermilk documentation

The structured documentation under `docs/` is still being written. For now, the most reliable references are:

- **[`README.md`](../README.md)** — installation, quickstart, and the public Python API surface.
- **[`examples/`](../examples/)** — runnable examples and notebooks for common patterns (flows, batch, visualisation, image analysis).
- **[`conf/`](../conf/)** — Hydra YAML configs for every flow, LLM profile, and pipeline mode.
- **[`CONTRIBUTING.md`](../CONTRIBUTING.md)** — development setup, test markers, release process.

A full documentation site (likely MkDocs Material) is on the roadmap — see the [`Best-in-class polish`](https://github.com/qut-dmrc/buttermilk/milestones) milestone.

If something here is missing or wrong, please [open an issue](https://github.com/qut-dmrc/buttermilk/issues/new/choose).
